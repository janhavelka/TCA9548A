enum class TCA9548A::Err : uint8_t
strong

Error codes for all TCA9548A operations.

Numeric values are an append-only compatibility contract. The synchronous core does not synthesize DEVICE_NOT_FOUND or IN_PROGRESS; it preserves specific I2C failures and requires terminal callback results.
